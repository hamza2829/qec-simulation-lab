# Experiment plan, declared before full simulation

This file fixes the settings before observing the surface-code sweep or training results. Do not replace the grid, seed, or model after seeing an unattractive crossing or ML comparison. Corrections to implementation bugs must be documented in verification history.

- Base seed: **20261102**. Every experiment uses a recorded integer derived by adding a fixed loop index, not Python's randomized hash.
- Full repetition: d=3,5,7,9; p=0.01,0.03,0.05,0.10,0.15,0.20,0.30,0.40,0.50; **100,000 shots per point**. Majority and minimum-weight syndrome lookup use the same errors. Unencoded counts use the first physical bit of those shots. Exact binomial tails and the analytical nontrivial break-even p=0.5 are separate from Monte Carlo estimates.
- NumPy phenomenological repetition: d=3,5; rounds=3,5; data p=0.02 per round; measurement q=0,0.02,0.05; **3,000 shots per setting**. Compare a full-history Viterbi path decoder, a decoder trusting the last noisy syndrome, and majority on perfect final data readout. Data errors accumulate; measurement faults do not change data. This is not a circuit simulation.
- Surface memory: Stim `surface_code:rotated_memory_z`, d=3,5,7, **rounds=d**, p=0.001,0.002,0.003,0.004,0.005,0.006,0.007,0.008,0.009,0.010,0.012,0.015; **100,000 shots per point**. Set `after_clifford_depolarization`, `before_round_data_depolarization`, `before_measure_flip_probability`, and `after_reset_flip_probability` all to p. Gate depolarization and reset/readout flips are different channels with the same numerical parameter. No coherent errors, leakage, crosstalk or explicit idle schedule.
- Decode with default, uncorrelated PyMatching MWPM from `detector_error_model(decompose_errors=True)`. Primary statistic: logical observable mismatch per whole memory experiment, not per gate. Record failure counts, 95% Wilson intervals, detector counts, active qubit counts, package versions and actual durations.
- Crossings: linear interpolation in p of pairwise differences of measured whole-experiment logical rates. Primary pair **d=5 vs d=7**, with d=3 vs 5 and d=3 vs 7 also reported. Always retain all sign-change roots; use the first nontrivial root in the fixed sweep for the stated estimate. **1,000 binomial bootstrap resamples** yield a conditional 95% percentile interval. Record no-crossing fractions. No threshold is invented if the curves do not cross in the grid. This does not quantify finite-size, interpolation or noise-model bias.
- Separate below-threshold scaling calibration: p_ref=**0.002**, d=3,5,7, rounds=d, **500,000 shots per distance**. Fit `log(P_block/d) = log(A) - ((d+1)/2) log(Lambda_ref)` using weighted least squares. Use `(failures+0.5)/(shots+1)` only for log-fit stabilization; raw counts/rates remain unchanged. Weights are `sqrt(failures+0.5)`. Bootstrap **1,000** times. Report any non-suppressing fitted slope or calibration point not below an identified primary crossing, rather than silently changing p_ref.
- Resource illustration: assume `Lambda(p)=Lambda_ref*p_ref/p`, an additional low-p power-law assumption, not independently fitted in p. Approximate `P_block(d,p)=d*A/Lambda(p)^((d+1)/2)` for rounds=d; choose the smallest odd d>=3 satisfying 1e-6 or 1e-9 at p=1e-3 or 1e-4. Physical memory-patch qubits=`2d²-1`; syndrome rounds=d. Report bootstrap intervals for required distances and flag extrapolation outside d=3,5,7. A fitted scale `p_ref*Lambda_ref` is not the measured crossing threshold.
- ML: two CPU MLPs (32 and 16 hidden ReLU units), Adam lr=0.003, batch size 1,024, **25 epochs**, **60,000 training**, **12,000 validation** and **40,000 independent test shots per noise point**. Predict one logical-observable bit from detector bits. Training probabilities: repetition 0.10; surface 0.01. Validation alone selects a decision threshold from 0.05,0.10,...,0.95, minimizing logical failures, with 0.5 preferred on ties. No test-set tuning or retraining. Train/test Stim sampler seeds are distinct. Repetition uses a custom Stim X_ERROR code-capacity circuit; surface uses the same noisy d=3, rounds=3 generator as the sweep.
- ML test probabilities: repetition 0.01,0.05,0.10; surface 0.003,0.01,0.02. Matching is constructed from the correct test-p error model, whereas the MLP and empirical lookup train at one fixed p; the resulting distribution shift is explicit. Repetition has an exact minimum-weight lookup decoder. Surface has a training-only empirical syndrome lookup, ties/unseen syndromes predicting 0. Report unseen fractions. All methods see identical held-out shots. Paired error-rate differences and approximate 95% normal intervals distinguish clear worse/better results from inconclusive differences; equal observed rates do not establish equivalence.
- CI/`--quick`: same grids/models, repetition 2,000 shots, phenomenology 128, surface 1,000, calibration 3,000, bootstrap 100, ML train 1,024 / validation 256 / test 512 / epochs 2. This is a smoke experiment; zero-count fits and unstable crossings must not be presented as validated science. Tests use still smaller fixed-seed fixtures.

All calculations are CPU-only. Fixed seeds do not guarantee bit-for-bit results across Stim versions, SIMD widths, platforms, or PyTorch releases. Record the environment. Full experiments, including weak/negative results, are committed under `results/`; CI writes only to `artifacts/`.
